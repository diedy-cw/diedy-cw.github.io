4口徑與假設

  1. 互斥可加總：本表 www 不含 web.cw.com.tw（拆列），故 www 比其深入報告的 258,390 低約 1,000。三個產品有深入報告：天下官網、csr × futurecity、併站情境評估。
  2. 未涵蓋的 14.8%（cw-web-prod 正式費用）：api-cw-com-tw（11 站共用 API）、api-app（天下 App 後端）、feature／topic／techtaiwan／ad／project／cw-hub／curation／ai-hub 等未列產品，與無法歸戶的殘餘流量。共用 API 若要攤回各站需另做呼叫來源分析。
  3. 方法沿用三站報告定版：2026-07 iKala 帳單（匯率 32.58、含稅 ×1.05）＋ CF GraphQL 全月流量＋ kubectl requests 快照（2026-08-20）。分攤鍵、共用 VM 處理、縮圖機 Referer 歸戶（無 Referer 的 9.8% 按可歸戶比例攤）均同。
  4. 各站 CMS（*.cwg.tw）灰雲直連：零 CF 份額；CMS 運算含在 cms cluster 欄。event／mkt／web 無獨立 CMS。opinion 與 crossing 的 dev 佔比含各自 dev CMS。
  5. event／mkt 幾乎是純流量成本：兩者 workload 極小（50m／20m CPU），費用主體是 CF 與網路——若未來下線或搬遷，GCP 側省不了什麼。
  6. 已知低估點：official cluster 尖峰 autoscale 至 2 台使 www 的 Compute 略被低估（v2 精算點）；bot 流量未剔除。
